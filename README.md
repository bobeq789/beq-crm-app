# beQ CRM (App-Dateien)

Dieses öffentliche Repository enthält nur die veröffentlichten App-Dateien des beQ CRM, für GitHub Pages.
Hier liegen keine Daten und keine geheimen Schlüssel. Der öffentliche Schlüssel in `config.js` ist dafür gedacht,
im Browser zu stehen. Die Daten schützen Anmeldung, zweiter Faktor und Zugriffsregeln in der Datenbank.

Bitte hier nichts von Hand ändern. Die Quelle ist das private Repository `bobeq789/bq_crm`, Ordner `app/`.
Von dort wird dieser Stand übertragen.
